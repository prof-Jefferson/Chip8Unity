# Chip8Unity

> Projeto educacional desenvolvido com Unity focado no ensino de Organização e Arquitetura de Computadores.

## Objetivo

Este projeto tem como objetivo a construção de uma máquina virtual baseada na arquitetura do **CHIP-8**, implementada na engine **Unity**, com foco no uso **pedagógico e visual**. A proposta visa facilitar a compreensão de conceitos fundamentais da disciplina de **Organização e Arquitetura de Computadores**, por meio da simulação gráfica de registradores, memória, decodificação de instruções e ciclo de execução.

## Contexto Educacional

Este emulador faz parte de um **projeto de pesquisa em desenvolvimento no Instituto Federal**, destinado ao ensino e à popularização de conceitos de baixo nível computacional. Ao utilizar uma engine moderna como Unity, aliamos interatividade e visualização para facilitar o aprendizado dos seguintes tópicos:

- Registradores e memória RAM
- Stack e Program Counter
- Unidade de controle e execução de instruções
- Decodificação de opcodes (CHIP-8)
- Simulação do ciclo de máquina

## Tecnologias Utilizadas

- Unity 6 (com suporte a 2D)
- C# (com orientação a objetos)
- Git (versionamento)
- GNU/Linux Ubuntu

## Funcionalidades previstas

- [ ] Tela gráfica 64x32 pixels
- [ ] Sistema de registradores (V0-VF, I)
- [ ] Temporizadores (delay e sound)
- [ ] Interpretação de instruções/opcodes
- [ ] Emulação do ciclo de execução
- [ ] Leitura de ROMs `.ch8`

## Uso Educacional

Este projeto pode ser utilizado em:
- Aulas práticas de arquitetura e organização de computadores
- Oficinas de introdução à computação de baixo nível
- Laboratórios interativos em cursos técnicos e de graduação
